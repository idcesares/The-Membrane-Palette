The starting point

A task worth examining.

Choose something specific: preparing feedback, adapting an explanation or planning a discussion.

Use an invented classroom scenario. Leave student names and personal information out of the exercise.

A learning journey

From a teaching question to a testable idea.

The sequence makes room for interpretation before a tool is chosen. These are proposed activities, not completed steps.

  1. Describe the situation

    Who needs support? What would a useful response make possible?

  2. Build a small example

    Write a prompt with context, a clear task and a way to inspect the answer.

  3. Compare and question

    Look for omissions and unsupported claims. Decide what still needs human review.

Before trying the exercise

Prepare a question, not a polished solution.

Write the task in a few sentences. Name one thing a model could miss. Decide how you would recognize a useful result before you generate one.
