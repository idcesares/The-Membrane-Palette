Accordion

Expandable sections on native <details>/<summary> — no script, keyboard-ready, exclusive with a shared name, animated where supported.

Examples Guidance API

Examples

FAQ

Do I need a framework?

No. Link one stylesheet and write HTML with mp- classes.

Does dark mode need extra CSS?

No. Every semantic token carries its own light and dark value.

Can agents use it?

Yes — start from components/manifest.json.

Guidance

Native disclosure: the browser handles keyboard, state and find-in-page (closed content is still searchable). Adjacent accordions share borders automatically. Give them the same name to make them exclusive (opening one closes the others).

Accessibility

  • <summary> is the button; don't put other interactive elements inside it.
  • Keep summaries short and descriptive — they're read as button labels.

States styled: :focus-visible :hover [open]. Set the native attribute or ARIA state; there are no state classes.

No component tokens: Accordion reads the semantic tokens directly.
